# Стоматология Марина

Премиальный сайт современной стоматологической клиники.

## Как открыть

Откройте `index.html` в браузере — сервер не обязателен.

Либо локально:

```bash
python3 -m http.server 8080
```

Затем перейдите на http://127.0.0.1:8080

## Состав

- `index.html` — одностраничник
- `css/style.css` — стили
- `js/main.js` — шапка, меню, форма записи
- `img/` — визуалы клиники и врачей

Демо-контент: адрес, телефон и цены можно заменить на реальные.
