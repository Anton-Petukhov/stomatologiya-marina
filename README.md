# Стоматология Марина

Премиальный одностраничный сайт современной стоматологической клиники.

Репозиторий: https://github.com/Anton-Petukhov/stomatologiya-marina

## Как открыть

```bash
git clone https://github.com/Anton-Petukhov/stomatologiya-marina.git
cd stomatologiya-marina
python3 -m http.server 8080
```

Затем откройте http://127.0.0.1:8080

Можно просто открыть `index.html` в браузере.

## Файлы

- `index.html` — страница
- `css/style.css` — стили
- `js/main.js` — меню и форма записи
- `img/` — фото ресепшна, кабинета и врачей
